import { Aside, Steps } from '@astrojs/starlight/components';

на сервер пускают по вайтлисту. заявку подаёшь через нашего бота
в телеграме, а он сообщит, приняли тебя или нет.

<Steps>

1. напиши боту [@pawsocks_robot](https://t.me/pawsocks_robot) и нажми `/start`.

2. отправь ему свой ник в майнкрафте одним сообщением.

3. дождись ответа: бот напишет, когда заявку рассмотрят.

4. заходи на сервер: адрес `femboys.zeroiq.club`, версия **1.21.11**.

</Steps>

<Aside type="tip" title="перед входом">
	загляни в [правила](/rules/) — заходя на сервер, ты соглашаешься с ними.
</Aside>
